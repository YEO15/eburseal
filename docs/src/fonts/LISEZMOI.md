# Polices embarquées

- **Liberation Serif** (Regular, Bold, Italic, BoldItalic) — métriquement identique à Times New Roman ; licence SIL Open Font License 1.1.
- **DejaVu Sans / DejaVu Sans Mono** — symboles ✔ ✘ et code ; licence libre DejaVu (dérivée de Bitstream Vera).

Elles sont incluses pour que `build.sh` produise le même rendu sur toutes les machines.
