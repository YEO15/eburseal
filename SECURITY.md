# Politique de sécurité

EburSeal est un projet pédagogique (SUP'COM — Sécurité Applicative), dépôt public. Si vous découvrez une vulnérabilité :

1. **N'ouvrez pas d'issue publique.** Signalez-la en privé via l'onglet **Security → Report a vulnerability** de ce dépôt (auteurs : OUATTARA Yacouba, YEO Tanna Daouda).
2. Décrivez le composant, les étapes de reproduction et l'impact (C / I / D).
3. Nous accusons réception sous 72 h ; un correctif critique est visé sous 7 jours (exigence SR-DEP-05).

Les exigences de sécurité du projet sont décrites dans [`docs/recueil_des_besoins.pdf`](docs/recueil_des_besoins.pdf)
et dans le référentiel [`docs/exigences.csv`](docs/exigences.csv).
